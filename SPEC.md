## Модель и функции

- Book: readonly id: string, title: string, authors: string[], year?: number, rating?: number.
- Catalog = Record<string, Book>; BookFilter = (book: Book) => boolean.
- formatBook: «Title (Year) — Author One, Author Two». Без года — без скобок. Рейтинг в эту строку не входит. Год 0 считается указанным.
- calculateAverageYear: среднее только известных годов, без округления; 0 при отсутствии таких книг. На странице средний год не нужен.
- addBook возвращает новый каталог, заменяет книгу с совпадающим ID. Одинаковые названия и авторы при разных ID разрешены.
- removeBook возвращает новый каталог без ID; отсутствие ID не является ошибкой. getBook возвращает книгу или undefined.
- Не мутировать исходный каталог, массив книг и объекты книг; глубокое копирование не требуется.
- Поиск автора: часть имени, без учёта регистра, запрос очищается от пробелов по краям. Пустой запрос не ограничивает поиск.
- Минимальный год/рейтинг включают границу; отсутствие соответствующего поля исключает книгу.
- applyFilters возвращает новый массив книг, удовлетворяющих всем фильтрам; пустой список фильтров сохраняет все книги.

## Данные формы

- ID генерируется через crypto.randomUUID().
- Название очищается от пробелов по краям и не может быть пустым.
- Авторы разделяются запятыми; каждый очищается через trim, пустые элементы удаляются. Должен остаться хотя бы один автор.
- Год и рейтинг необязательны: отсутствующие или пустые после trim значения дают undefined.
- Год — конечное целое число, включая 0, отрицательные и будущие значения.
- Рейтинг — конечное число от 0 до 5 включительно. Сообщение ошибки: «Рейтинг должен быть числом от 0 до 5».
- Нельзя принимать частично числовые строки вроде 2024abc или 4.5abc. Использовать полное преобразование Number с проверкой результата вместо частичного разбора parseInt/parseFloat.

## Интерфейс

- Исправить импорты в main.ts под существующие файлы в src/.
- Оставить две исходные демонстрационные книги. Состояние — Catalog в памяти; обновление страницы сбрасывает данные.
- Отправка существующей формы добавляет книгу, обновляет список, очищает форму только при успехе.
- Ошибки показываются под формой; введённые данные при ошибке сохраняются. Элемент сообщения создаётся средствами DOM из main.ts.
- Фильтры автора и года применяются только по существующей кнопке «Применить». Новые значения полей не действуют до нажатия.
- После добавления или удаления сохраняются последние применённые фильтры.
- Кнопка удаления создаётся при отрисовке каждой карточки через DOM; удаление сразу, без подтверждения.
- Использовать textContent для пользовательских строк. Можно отдельно показывать рейтинг, если он есть у книги.
- Поля рейтинга и фильтра рейтинга в исходном HTML отсутствуют: не добавлять их. Соответствующие функции реализуются по заданию.
